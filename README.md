# Balanse — Bills & Loans Calendar

**Balanse** is a personal finance tracker built with React + TypeScript + Vite. It provides a beautiful monthly calendar to visualise your bills, loans, and income — helping you stay ahead of your cash flow.

## Tech Stack

- React 19 + TypeScript
- Vite + Tailwind CSS v4
- PWA via `vite-plugin-pwa`

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Features

- Monthly calendar view for bills & loans
- Income & balance forecast
- Work earnings calculator
- Multi-currency support
- 4 themes: Dark, Light, Beige, Sage
- PWA installable (home screen icon on iOS/Android)
- Local JSON backup & restore
